# Data

## Provenance

The `.abf` files in `data/raw/` are raw single-channel patch-clamp recordings of **wild-type CFTR**, provided by the lab (originally from Guiying). Guiying went back to old records and broke them into 60-second chunks; most chunks look like **1 channel present**, recorded at a high sampling rate.

Two datasets are present:

| Dataset | Files | Notes |
|---|---|---|
| Dataset 1 | `03n17000.abf` – `03n17037.abf` (38 files) | First dataset |
| Dataset 2 | `03n18023.abf` – `03n18037.abf` (15 files) | Second dataset, used to refresh caches in later analyses |

Both datasets come from one recording of WT-CFTR **in the absence and presence of 50 µM glibenclamide**. Glibenclamide enters the cytoplasmic entrance of the channel pore and its kinetics are completely different from those of normal channel closure — the difference between pore dynamics and gating dynamics is what makes the data interesting. Its action is voltage-dependent; it can enter in two ways (polar, charged) — one yields blocking times of a few ms, the other 10+ ms.

**Rights note**: the recordings are lab-provided and not for redistribution. No license is declared anywhere in this repository; all rights reserved.

**Anomaly**: `03n17005.abf` is 193 KB while every other recording is ~1.2 MB — likely a short or aborted recording.

## How notebooks reference recordings

Notebooks reference recordings **by index** into the sorted file listing produced by `AxonData(dirname=...)` (see `source/moreka.py`). Sorted order: `03n17000`–`03n17037` occupy indices 0–37, `03n18023`–`03n18037` occupy indices 38–52. Indices used by the committed notebooks:

| Index | File | Used by |
|---|---|---|
| 3 | `03n17003.abf` | `code/04_ml/LSTM_normalized_50_50_real_data.ipynb` |
| 21 | `03n17021.abf` | `code/03_classical/on_real_data.ipynb` |

The full set of files must be present for indices to reproduce correctly.

## Format

ABF (Axon Binary Format) files. They are read with the `neo` library:

```python
import neo
axon_io = neo.io.AxonIO(filename="data/raw/03n17000.abf")
block = axon_io.read_block(lazy=False)
signal = block.segments[0].analogsignals[0]
```

or via the repo helper:

```python
from source.moreka import AxonData
data = AxonData(dirname="data/raw")
df = data[0]  # pandas DataFrame with 'time' and 'signal' columns
```

## Derived artifacts

`data/derived/synth_v1/` holds the frozen synthetic benchmark (generated by `python code/04_ml/benchmark.py --generate`, seed-controlled; `data/raw/` is never touched). It reproduces the simulator exactly (validated against `source/ion_channel.py` + `source/patch_clamp.py`: per-open-count means/stds match to 3 decimals) with an independent RNG, and fixes the thesis protocol gaps (separate val and test, fixed seeds, frozen files).

| File | Traces × samples | Content |
|---|---|---|
| `train.npz` | 1500 × 1000 | N ∈ {1,2,3}, noise ×1 |
| `train_wide.npz` | 3000 × 1000 | N ∈ {1..5}, per-trace noise scale ∈ [1,4] (`X`, `trace_scale`) — KI-HMM training set |
| `val.npz` | 300 × 1000 | N ∈ {1,2,3}, noise ×1 |
| `test.npz` | 600 × 1000 | N ∈ {1,2,3} at noise ×1, ×2, ×4 (`X_s1`, `X_s2`, `X_s4` share one noise realization) |
| `extrap.npz` | 400 × 1000 | N ∈ {4,5} at noise ×1, ×2 (channel-count extrapolation) |
| `mismatch_lowpass.npz` | 200 × 100 | noise ×1 then moving-average (15) + decimation (10) |
| `mismatch_gaussian.npz` | 200 × 1000 | Gaussian noise with matched per-state std instead of GH |
| `mismatch_corr.npz` | 200 × 1000 | AR(1) correlated noise, ρ = 0.9 |
| `mismatch_drift.npz` | 200 × 1000 | kinetics ×3 faster in the second half of each trace |

Each archive stores `X_s<scale>` (observed sum, float32), `y` (true open count, int8), `N` (true channel count, int8), `r` (per-channel 7-state index, padded with −1) and a `meta_json` string. Noise-model facts used: open-state GH `(p,a,b,loc,scale) = (1.9865, 0.0020, −0.00056, 1.40, 2.07e−4)`, closed `(3.6662, 0.5836, 0.1686, 0.58, 0.0242)`; the open noise is heavy-tailed (per-channel std 0.232) and must be convolved exactly in likelihood-based decoders.
